## Tech Stack

- React Native
- Nativewind
- Expo
- Google Cloud

## Key Features

- Map
- Estimated time
- Distance

## What I Built

- Built map with Map Platform API & React Native Maps
- Estimated time of travel
- Distance

## Technical Decisions

- Used Google Cloud and Maps Platform API because of the amount of information given
- Used React-Native-Maps because of its compatibilty with Maps Platform API and Nativewind CSS

## Getting Started

```bash
git clone YOUR_REPOSITORY_URL
cd PROJECT_FOLDER
npm install
npm run dev
```
